# Homework 2 — How Many Samples?
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Homework 2 for [BEE 4850/5850](https://envdata.viveks.me), Spring 2027. Due **Thu 11 Feb 2027**.
Covers Week 2: probability review, Monte Carlo, convergence and standard error.

## Learning Objectives

- state what unbiasedness and the law of large numbers do and do not guarantee about a Monte Carlo estimator;
- relate Monte Carlo standard error to sample size and size a simulation accordingly;
- judge convergence from a running-mean diagnostic rather than the value it appears to settle at;
- estimate a probability by simulation, report its standard error, and distinguish model error from Monte Carlo error.
